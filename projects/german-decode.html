02 / Project Overview

The idea behind
German Decode.

The Challenge

Producing educational Shorts manually requires researching topics, preparing scripts, generating narration, editing visuals, exporting videos, and uploading content to YouTube.

Repeating these steps for every video creates a time-consuming production process.

The Solution

Connect content generation, audio creation, frame rendering, video assembly, and publishing into a repeatable workflow.

GitHub Actions coordinates scheduled execution, while Python and FFmpeg handle video-production tasks.

03 / Automation Architecture

How the
workflow operates.

The pipeline connects several production stages to generate and publish educational Shorts with reduced manual intervention.

01

Topic Selection

Select a German-language learning topic for the scheduled content series.

02

AI-Assisted Content

Prepare structured educational content, example phrases, and explanations.

03

Narration & Audio

Produce the audio used for the educational video.

04

Visual Rendering

Build portrait video frames using reusable layouts and colour themes.

05

Video Assembly

Combine visuals and audio into a vertical MP4 using FFmpeg.

06

YouTube Publishing

Upload the completed video through authorized YouTube API access.
