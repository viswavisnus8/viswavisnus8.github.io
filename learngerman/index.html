HOW TO STUDY

Four ways to practise.

🎧 Listen first

Play dialogues using available German text-to-speech and repeat aloud. Use the visible transcript whenever audio is unavailable.

🗣️ Speak out loud

Read a dialogue as both speakers. Compare your pronunciation with the browser voice if available; automated speech scoring is not provided.

✍️ Write something

After each lesson, write two original sentences using the new words. Review them against the examples and grammar tip.
